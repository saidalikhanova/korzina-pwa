# Тренажёры «Корзина» — PWA

Десять учебных практикумов (подготовка к PSM I, нарезка эпика, канбан-доска, метрики потока, дорожная карта, стейкхолдеры, реестр рисков, планирование спринта, освоенный объём, встреча с партнёрами) на кейсе вымышленного маркетплейса «Корзина», собранные как прогрессивное веб-приложение.

## Состав
- `index.html` — стартовая страница со списком тренажёров
- `psm.html`, `epic.html`, `board.html`, `roadmap.html`, `stakeholders.html`, `risks.html`, `flow.html`, `sprint.html`, `evm.html`, `facilitation.html` — практикумы (каждый самодостаточен)
- `manifest.webmanifest` — манифест PWA (имя, иконки, цвета)
- `sw.js` — service worker: кэширует все файлы, тренажёры работают офлайн после первого открытия
- `pwa-shim.js` — заменяет среду Claude: кнопка «Скачать отчёт» сохраняет файл через браузер; вызовы ИИ (`sample`) недоступны, страницы показывают встроенные примеры
- `icons/` — иконки 192 и 512 px

## Размещение
PWA требует HTTPS (или `localhost`). Подойдёт любой статический хостинг: GitHub Pages, Netlify Drop, Cloudflare Pages, папка на собственном сайте.

1. Загрузите содержимое папки целиком, не меняя структуру (`index.html` должен быть в корне папки, `sw.js` рядом с ним).
2. Откройте адрес папки в браузере. На телефоне появится предложение «Добавить на главный экран» (Android — автоматически, iOS — через меню «Поделиться» → «На экран „Домой“»).
3. При обновлении файлов поменяйте имя кэша в `sw.js` (`korzina-trainers-v3` → `v4`), иначе пользователи увидят старую версию до перезапуска.

## Локальная проверка
В папке выполните `python3 -m http.server 8080` и откройте `http://localhost:8080/`.

## Ограничения
- Прогресс хранится в `localStorage` браузера на устройстве, между устройствами не переносится.
- Шрифты Google Fonts подгружаются из сети; офлайн подставляются системные.
- Разбор с помощью ИИ работает только в версиях-артефактах на claude.ai.
