# Тренажёры «Корзина» — PWA

Десять учебных практикумов по Scrum, Kanban и PMBOK 8 на одном вымышленном кейсе маркетплейса «Корзина» (одежда, посуда и товары для дома, запуск направления «Доставка еды»). Автор контента — Бибигуль Сайдалиханова, Scrum Way Academy. Язык — русский.

## Структура
- `index.html` — лаунчер со списком практикумов.
- `psm.html`, `epic.html`, `board.html`, `roadmap.html`, `stakeholders.html`, `risks.html`, `flow.html`, `sprint.html`, `evm.html`, `facilitation.html` — практикумы. Каждый самодостаточен: один файл, инлайн-стили и один инлайн-скрипт, без сборки и внешних библиотек. Шрифты — Google Fonts (Dela Gothic One, Golos Text; в `epic.html` и `facilitation.html` — Unbounded, IBM Plex).
- `pwa-shim.js` — подключается в `<head>` каждой страницы. Подменяет среду claude.ai: `window.claude.use('downloads')` возвращает объект с `save({filename, data})`, который сохраняет файл через Blob; всё остальное (`sample` — вызовы ИИ) возвращает `null`, и страницы показывают встроенные примеры. Также регистрирует `sw.js`.
- `sw.js` — service worker: cache-first для своих файлов, network-first для шрифтов. Имя кэша `korzina-trainers-v3`; при любом изменении файлов поднимать версию.
- `manifest.webmanifest`, `icons/` — манифест и иконки 192/512 (плюс maskable).

## Инварианты (не ломать)
- Страницы работают и в claude.ai как артефакты (там есть настоящий `window.claude.use`), и в PWA (через shim). Любая новая возможность должна проверять `window.claude && window.claude.use` и деградировать до `null`.
- Прогресс хранится в `localStorage` под ключами `kz.<slug>.state` (и `kz.psm.custom` для своих вопросов), всегда в try/catch.
- Числа кейсов, эталонные ответы и намеренные ошибки «ответа ИИ» — часть педагогики; менять только вместе с проверками.
- Никаких реальных компаний и никакого телекома в текстах: кейс «Витрина», компания «Корзина», релизный комитет по четвергам, 12 специалистов отдела операций, 4 уходят на запуск с 18-й недели, запуск на 35-й.
- Светлая и тёмная тема через CSS-переменные (`prefers-color-scheme` + `[data-theme]`), мобильная ширина 390 px без горизонтального скролла.

## Проверка
- `python3 -m http.server 8080` и открыть `http://localhost:8080/` — PWA требует HTTPS или localhost.
- Для каждой страницы: нет ошибок в консоли, кнопка «Скачать отчёт» сохраняет файл, прогресс переживает перезагрузку.
- Извлечь `<script>` и прогнать `node --check`.

## Что обычно просят сделать дальше
1. Вход по e-mail и синхронизация прогресса между устройствами (Supabase или Firebase; `localStorage` остаётся офлайн-кэшем).
2. Серверный ИИ-разбор: собственный бэкенд с вызовом модели и лимитом на пользователя; на страницах заменить `sample === null` на вызов этого бэкенда.
3. Панель руководителя команды: кто прошёл, средняя точность, типовые ошибки.
4. Оплата (Kaspi Pay для Казахстана, карта для СНГ) и командные лицензии.
5. Публикация: GitHub Pages / Netlify / Cloudflare Pages, папка целиком, без изменения структуры.
